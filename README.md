# GastroPlan 4.4 – Verfügbarkeiten

Neu in dieser Version:

- Mitarbeiteransicht für die eigene Wochenverfügbarkeit
- Verfügbar, teilweise verfügbar, nicht verfügbar, Urlaub, Krank und Berufsschule
- Uhrzeiten bei teilweiser Verfügbarkeit
- Freie Bemerkung je Tag
- Farbige Ampelanzeige für den Planer
- Übersicht über fehlende Rückmeldungen
- Warnung, wenn trotz Nichtverfügbarkeit eine Schicht geplant wird
- Lokale Speicherung im Browser
- Erweitertes Supabase-Schema als Cloud-Fundament
